# Example Briefing for macOS

Briefing for the agent driving this computer:
- You are running on macOS 26, a single 1280×800 (Retina) display.
- You control it through the conductor-desktop MCP tools. How to use them (which channel to pick, how to look and act, the gotchas) comes with the server: its instructions and each tool's description. This file only covers what the server can't know about this machine.
- You are running from within Terminal. Don't close your own terminal; minimise it if it's in the way.
- If the conductor-desktop tools aren't enough, you can use the shell.

About this machine:
- The interface language is English.
- Spotlight (cmd+space, type the name, enter) is the quickest way to open an app. The menu bar belongs to the frontmost app, so focus the app before reading or using its menus.
- Chrome runs with remote debugging on, so the web_* tools can drive its tabs.
