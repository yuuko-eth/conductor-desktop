# Example Briefing for Windows

Briefing for the agent driving this computer:
- You are running on Windows 11 Pro, a single 1920×1080 display at 100% scaling.
- You control it through the conductor-desktop MCP tools. How to use them (which channel to pick, how to look and act, the gotchas) comes with the server: its instructions and each tool's description. This file only covers what the server can't know about this machine.
- You are running from within Windows Terminal (PowerShell). Don't close your own terminal; minimise it if it's in the way.
- If the conductor-desktop tools aren't enough, you can use the shell. It is PowerShell, not bash.

About this machine:
- The interface language is English.
- The Start menu (the win key, type the name, enter) is the quickest way to open an app.
- Chrome runs with remote debugging on, so the web_* tools can drive its tabs.
